# 项目概述

## 项目背景
DeepExiLab Frontend（DeepExiLab前端）是一个专业的企业级AI/ML全生命周期开发平台。该系统为AI/ML工程团队提供完整的前端界面，涵盖数据集管理、数据标注、模型训练、模型管理、模型评估等AI模型开发的全生命周期功能，同时支持在线Notebook环境、实验管理以及系统性能监控等高级功能的用户交互。

## 核心愿景
构建一个现代化、可扩展、高可用的AI模型全生命周期开发平台，使数据科学家和ML工程师能够通过直观的用户界面高效地完成从数据准备、模型训练到部署评估的完整AI开发工作流程，支持大规模分布式任务处理和企业级生产应用。

## 主要目标

### 1. 数据集全生命周期管理界面
- **数据集组织化管理**：支持目录结构化组织，包含元数据、上下文信息、标准答案等完整数据要素的前端展示
- **版本控制与追溯**：完整的数据变更历史记录和日志追踪能力的前端界面
- **多格式数据导入导出**：支持JSON、Excel等多种格式的批量数据操作的前端交互

### 2. 智能化提示词管理界面
- **提示词模板系统**：支持Jinja2模板格式的动态提示词生成的前端编辑器
- **LangChain集成**：原生支持ChatPromptTemplate和消息模板系统的前端配置
- **变量映射与参数化**：灵活的输入变量管理和模板渲染机制的前端界面

### 3. 大规模模型评估框架界面
- **分布式任务执行**：基于前端界面的任务创建、监控和管理
- **多模型配置管理**：支持OpenAI、自定义LLM等多种模型配置和参数管理的前端界面
- **综合评估指标**：内置多种评估指标，支持自定义G-Eval指标扩展的前端展示

### 4. 基于Kubernetes的微调任务管理界面
- **K8s资源调度**：支持基于Kubernetes的微调任务资源管理和动态调度的前端界面
- **项目命名空间隔离**：每个项目对应独立的K8s命名空间，确保资源隔离的前端展示
- **智能资源分配**：根据任务需求自动分配CPU、内存、GPU和存储资源的前端配置
- **多集群支持**：支持跨多个Kubernetes集群的统一任务调度和管理的前端界面
- **资源监控与优化**：实时监控任务资源使用情况，提供性能优化建议的前端展示

### 5. 在线Notebook交互式编程环境
- **Web化Notebook环境**：提供基于JupyterLab的Web版本Notebook，支持Python、R、Julia等多种编程语言
- **秒级启动体验**：基于容器化技术的快速启动，支持预配置模板和自定义环境
- **智能资源管理**：GPU资源智能分配，支持A100、H100、V100等多种GPU类型的动态配置
- **数据无缝集成**：直接访问项目数据集，支持多种存储后端和数据源连接
- **协作与共享**：支持团队协作、结果分享和代码版本控制
- **生命周期管理**：智能的自动回收机制，支持实例状态监控和资源优化

### 6. 企业级前端架构
- **现代化前端技术栈**：基于React + TypeScript + Vite的现代化前端架构
- **组件化设计**：基于Ant Design的组件库，支持高度可定制的UI组件
- **状态管理**：基于Zustand的轻量级状态管理，支持复杂应用状态管理
- **国际化支持**：完整的i18n国际化支持，支持多语言界面

### 7. 统一前端API架构
- **Mock数据服务**：完整的前端Mock数据服务，支持开发阶段的数据模拟
- **API接口规范**：标准化的前端API调用接口，支持与后端服务的无缝集成
- **错误处理**：统一的前端错误处理和用户提示机制
- **加载状态管理**：完整的加载状态和进度展示机制

## 核心功能模块

### 1. 小模型调参功能界面（轻量级AI模型快速调优）
- **功能定位**：专门针对轻量级AI模型的快速调参优化平台前端界面
- **适用场景**：小规模数据集（10万条以下）、轻量级模型（10B参数以下）
- **核心优势**：
  - 快速训练：30分钟-6小时内完成模型训练的前端配置
  - 资源节约：单GPU即可满足训练需求的前端展示
  - 易于使用：无代码拖拽式配置界面
- **使用流程**：选择模板 → 配置参数 → 快速训练 → 一键部署

### 2. 大模型调优功能界面（企业级大模型微调平台）
- **功能定位**：基于Kubernetes的企业级大模型微调平台前端界面
- **适用场景**：大规模数据集（百万条以上）、大型模型（7B参数以上）
- **核心优势**：
  - 企业级：支持大规模分布式训练的前端配置
  - 高性能：基于Kubernetes资源管理的前端展示
  - 生产就绪：面向企业级部署场景的前端界面
- **使用流程**：数据准备 → 创建精调任务 → 分布式训练 → 发布模型

### 功能差异化定位

#### 小模型调参 vs 大模型调优对比

| 维度 | 小模型调参 | 大模型调优 |
|------|------------|------------|
| **目标用户** | 快速原型验证、小规模应用 | 企业级生产部署 |
| **数据规模** | 10万条以下 | 百万条以上 |
| **模型规模** | 10B参数以下 | 7B参数以上 |
| **训练时间** | 30分钟-6小时 | 数小时-数天 |
| **资源需求** | 单GPU | 多GPU集群 |
| **技术复杂度** | 无代码配置 | 专业参数调优 |
| **部署场景** | 边缘设备、小型应用 | 企业级生产环境 |

### 大模型调优页面优化

#### 设计理念
- **流程可视化**：通过四步流程指引，帮助用户理解使用方法
- **特点突出**：通过特点展示区域突出企业级、高性能、生产就绪的核心优势
- **专业化表达**：使用"精调"、"作业"等更专业的术语

#### 界面改进
- **视觉风格**：采用现代化卡片式设计，保持视觉一致性
- **交互模式**：采用统一的布局结构和交互方式
- **组件规范**：统一使用Ant Design组件库，确保组件风格一致
