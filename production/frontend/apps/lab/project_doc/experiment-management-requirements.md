# 实验管理需求文档

## 文档概述

本文档详细描述了"我的实验"功能模块的需求规格和技术实现方案。实验管理模块是一个完整的机器学习实验跟踪和管理平台，为数据科学家和机器学习工程师提供实验全生命周期管理功能。

## 功能定位

**实验管理模块**是面向机器学习研发人员的专业实验管理和结果追踪平台，主要解决：
- 实验版本管理和追踪问题
- 模型参数和性能对比分析
- 实验结果可视化和报告生成
- 团队协作和知识共享

**目标用户**：
- 数据科学家
- 机器学习工程师
- 算法研究人员
- AI产品经理

## 核心功能需求

### 1. 实验项目管理 ✅ 已实现

#### 1.1 实验项目基础管理
- **实验项目创建**: 支持在项目下创建机器学习实验项目，每个实验项目对应一个研究目标
- **实验项目列表**: 展示项目下所有实验，包括实验名称、描述、运行数量、状态、创建时间等
- **实验项目搜索**: 支持按实验名称、描述、标签进行模糊搜索和筛选
- **实验项目状态管理**: 支持实验状态管理（活跃、已完成、已归档、已删除）
- **实验统计信息**: 显示实验的运行总数、成功数、失败数、平均运行时长、最佳指标等
- **项目级权限控制**: 继承系统的项目级权限管理，确保实验数据的安全隔离

#### 1.2 实验元数据管理
- **实验基础信息**:
  - `id`: 唯一标识符
  - `name`: 实验名称（必填）
  - `description`: 实验描述
  - `tags`: 标签列表（如：['CV', 'YOLO', '目标检测']）
  - `status`: 实验状态（active、completed、archived、deleted）
  - `project_id`: 关联项目ID
- **实验统计数据**:
  - `run_count`: 运行总数
  - `success_count`: 成功运行数
  - `failed_count`: 失败运行数
  - `avg_duration`: 平均运行时长
  - `best_metric`: 最佳性能指标
- **时间跟踪**:
  - `created_at`: 创建时间
  - `updated_at`: 最后更新时间
  - `last_run_at`: 最后运行时间

### 2. 实验运行记录管理 ✅ 已实现

#### 2.1 运行记录基础功能
- **运行记录列表**: 展示实验下所有运行记录，包括运行名称、状态、时长、创建者、创建时间等
- **运行状态跟踪**: 支持运行状态的实时更新和展示
  - `RUNNING`: 运行中（绿色标识）
  - `FINISHED`: 已完成（蓝色标识）
  - `FAILED`: 失败（红色标识）
  - `KILLED`: 已终止（灰色标识）

#### 2.2 运行记录筛选功能
- **多维度筛选**:
  - 按状态筛选：运行中、已完成、失败、已终止
  - 按时间范围筛选：今天、本周、本月、自定义时间段
  - 按创建者筛选：当前用户、团队成员、全部
  - 按模型类型筛选：文本生成、图像分类、目标检测等
- **排序功能**:
  - 创建时间（默认降序）
  - 运行时长（升序/降序）
  - 模型性能评分（降序）
  - 运行状态（按优先级排序）
- **搜索功能**:
  - 按运行名称搜索
  - 按标签搜索
  - 按参数值搜索
  - 按模型类型搜索

#### 2.3 运行记录数据结构
- **运行基础信息**:
  - `id`: 运行记录唯一标识
  - `name`: 运行名称
  - `experiment_id`: 关联实验ID
  - `status`: 运行状态
  - `start_time`: 开始时间
  - `end_time`: 结束时间
  - `duration`: 运行时长（秒）
  - `created_by`: 创建者
- **性能指标**:
  - `metrics`: 性能指标字典（如：accuracy、loss等）
  - `best_metric_value`: 最佳指标值
  - `metric_trend`: 指标变化趋势
- **资源使用**:
  - `gpu_hours`: GPU使用时长
  - `cpu_usage`: CPU使用率
  - `memory_usage`: 内存使用量
  - `cost`: 运行成本

### 3. 实验参数和指标管理

#### 3.1 参数管理功能
- **超参数记录**: 自动记录训练超参数（学习率、批次大小、优化器、正则化等）
- **模型参数**: 记录模型结构参数（网络架构、层数、隐藏单元数等）
- **数据参数**: 记录数据集信息（训练集大小、验证集比例、数据增强策略等）
- **环境参数**: 记录运行环境信息（Python版本、框架版本、硬件配置等）
- **参数历史**: 支持参数配置的历史版本管理和对比
- **参数模板**: 支持参数配置模板的创建和复用

#### 3.2 指标管理功能
- **核心指标**: 支持常见ML指标的记录和展示
  - 分类任务：准确率、精确率、召回率、F1分数、AUC-ROC、AUC-PR
  - 回归任务：MSE、RMSE、MAE、R²、MAPE
  - 生成任务：BLEU、ROUGE、METEOR、CIDEr
  - 训练指标：损失值、梯度范数、学习率变化
- **自定义指标**: 支持用户自定义指标的定义、计算和展示
- **指标实时更新**: 支持训练过程中指标的实时更新和显示
- **指标历史记录**: 完整保存指标的历史变化记录

#### 3.3 指标可视化
- **训练曲线**: 实时展示训练过程中的损失和准确率变化
- **多指标对比**: 支持多个指标在同一图表中的对比展示
- **图表类型**: 支持多种可视化图表
  - 折线图：展示指标随时间的变化趋势
  - 柱状图：展示不同运行的指标对比
  - 散点图：展示参数与指标的相关性
  - 热力图：展示参数空间的性能分布
- **交互功能**: 支持图表的缩放、平移、数据点查看等交互操作

### 4. 实验对比分析 ✅ 已实现

#### 4.1 多运行对比功能
- **对比选择**: 支持同时选择多个运行进行对比（建议2-10个）
- **对比维度**: 支持多维度的对比分析
  - 参数对比：并排展示不同运行的参数配置
  - 指标对比：对比不同运行的性能指标
  - 时间对比：对比不同运行的训练时间和资源使用
  - 模型对比：对比不同模型架构的性能表现

#### 4.2 对比展示方式
- **对比表格**: 以表格形式展示所有对比项的详细信息
- **对比图表**: 提供多种图表形式的可视化对比
  - 雷达图：展示多个指标的综合对比
  - 平行坐标图：展示多维参数空间的对比
  - 箱线图：展示指标分布的对比
  - 散点图：展示参数与性能的关系对比

#### 4.3 智能分析功能
- **最佳运行识别**: 自动识别和高亮最佳性能的运行记录
- **性能排名**: 根据关键指标对运行进行排名
- **参数重要性分析**: 分析哪些参数对性能影响最大
- **趋势分析**: 分析实验的改进趋势和发展方向

#### 4.4 对比报告生成
- **自动报告**: 自动生成包含图表和分析结论的对比报告
- **报告导出**: 支持多种格式的报告导出（PDF、Word、Excel）
- **报告分享**: 支持报告的团队内分享和协作讨论

### 5. MLflow深度集成

#### 5.1 MLflow服务器管理
- **连接配置**: 支持MLflow服务器的连接配置和管理
  - 服务器地址配置
  - 认证信息管理
  - 连接测试和验证
- **多实例支持**: 支持多个MLflow实例的统一管理
  - 不同环境的MLflow实例（开发、测试、生产）
  - 不同项目的MLflow实例
  - 实例间的数据同步和迁移
- **健康监控**: 支持MLflow服务器的健康检查和监控
  - 连接状态监控
  - 响应时间监控
  - 错误率监控

#### 5.2 数据同步机制
- **实时同步**: 支持与MLflow的实时数据同步
  - 实验创建的实时同步
  - 运行状态的实时更新
  - 指标数据的实时传输
- **批量同步**: 支持批量数据的同步和导入
  - 历史数据的批量导入
  - 增量数据的定期同步
  - 数据一致性检查
- **冲突处理**: 支持数据冲突的检测和解决
  - 冲突检测算法
  - 冲突解决策略
  - 数据备份和恢复

#### 5.3 模型管理集成
- **Model Registry**: 集成MLflow Model Registry功能
  - 模型注册和版本管理
  - 模型状态管理（Staging、Production、Archived）
  - 模型部署和监控
- **模型性能监控**: 支持模型在生产环境的性能监控
  - 实时性能指标监控
  - 数据漂移检测
  - A/B测试支持

## 技术实现方案

### 6.1 前端架构
- **技术栈**: React + TypeScript + Ant Design
- **状态管理**: 使用现代状态管理方案，确保数据一致性
- **组件设计**: 高度可复用的组件设计，符合原子设计原则
- **响应式设计**: 适配不同屏幕尺寸的设备访问
- **国际化支持**: 支持中文界面，预留多语言扩展

### 6.2 数据服务
- **Mock数据服务**: 初期使用Mock数据服务，快速验证功能需求
- **API接口设计**: RESTful API设计，支持标准CRUD操作
- **数据结构**: 完整的TypeScript类型定义，确保类型安全
- **数据同步**: 支持与后端MLflow服务的数据同步

### 6.3 性能优化
- **虚拟滚动**: 支持大量数据展示，提升列表性能
- **分页加载**: 优化用户体验，减少初始加载时间
- **图表懒加载**: 减少初始页面加载时间
- **缓存策略**: 智能缓存常用数据，提升响应速度

### 6.4 安全性
- **权限继承**: 继承系统的认证和授权机制
- **数据加密**: 敏感数据加密存储
- **操作审计**: 完整的操作日志记录和审计
- **项目隔离**: 确保不同项目间的数据安全隔离
