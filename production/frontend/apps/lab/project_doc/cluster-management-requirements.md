# 集群管理产品需求文档

## 1. 产品概述

### 1.1 产品定位
集群管理模块是DeepEXI Lab平台的核心基础设施管理组件，负责Kubernetes集群的连接、配置、监控和资源管理。

### 1.2 核心价值
- **统一管理**：提供统一的Kubernetes集群管理界面
- **简化运维**：降低集群管理的复杂度和人工操作成本
- **资源可视化**：直观展示集群状态和资源使用情况


## 2. 功能需求

### 2.1 集群连接管理

#### 2.1.1 集群导入
- **功能描述**：支持通过kubeconfig文件导入现有Kubernetes集群
- **输入要求**：
  - kubeconfig文件内容（必填）
  - 集群别名（可选，默认取kubeconfig中的集群名）
  - 连接验证开关（可选，默认开启）
- **验证规则**：
  - kubeconfig格式验证
  - 集群连通性验证
  - 权限验证（确保具有必要的RBAC权限）
- **成功标准**：集群成功导入且状态显示为"在线"

#### 2.1.2 集群连接状态
- **状态类型**：
  - `online`：集群连接正常，可以正常通信
  - `offline`：集群暂时不可达，可能是网络问题
  - `error`：集群配置错误或权限不足
- **状态显示统一**（2024年更新）：
  - **测试通过**：对应`online`状态，显示绿色勾号
  - **测试失败**：对应`offline`和`error`状态，统一显示红色叉号
  - 简化用户理解，所有异常情况统一为测试失败
- **状态检测**：
  - 实时状态检测机制
  - 定期健康检查（每5分钟）
  - 手动刷新状态功能

### 2.2 集群信息展示

#### 2.2.1 基本信息
- **集群标识**：
  - 集群名称（支持编辑）
  - 集群ID（系统生成，只读）
  - API Server地址
  - 集群版本
- **运行状态**：
  - 连接状态（在线/离线/错误）
  - 节点数量
  - 创建时间和更新时间

#### 2.2.2 标签和标记
- **标签系统**：
  - 支持自定义key-value标签
  - 标签用于集群分类和筛选
  - 标签格式：environment=production, team=devops
- **显示优化**：
  - 列表中最多显示2个标签，超出部分显示"+N"
  - 鼠标悬停显示完整标签列表
  - 标签宽度限制，避免界面溢出

### 2.3 集群编辑管理

#### 2.3.1 基本信息编辑
- **可编辑字段**：
  - 集群名称
  - 标签配置
- **不可编辑字段**：
  - 集群ID
  - API Server地址
  - 连接凭证信息

### 2.4 集群操作管理

#### 2.4.1 删除集群
- **删除条件**：
  - 确认集群当前没有正在运行的任务
  - 用户确认删除操作
- **删除后果**：
  - 移除集群配置信息

  - 记录删除操作日志

#### 2.4.2 批量操作
- **支持操作**：
  - 批量标签更新
  - 批量状态刷新
  - 批量导出配置

### 3.3 编辑模态框
- **表单设计**：
  - 集群名称输入框

  - 实时表单验证

## 4. 技术要求

### 4.1 数据模型
```typescript
interface KubernetesCluster {
  id: string;                      // 集群唯一标识
  name: string;                    // 集群名称
  server: string;                  // API Server地址
  status: 'online' | 'offline' | 'error';  // 连接状态
  context: string;                 // kubectl上下文
  currentContext: string;          // 当前上下文
  createdAt: string;              // 创建时间
  updatedAt: string;              // 更新时间
  version?: string;               // 集群版本
  nodeCount?: number;             // 节点数量
  certificateAuthority?: string;   // CA证书（脱敏）
  clientCertificate?: string;      // 客户端证书（脱敏）
  clientKey?: string;             // 客户端密钥（脱敏）
  token?: string;                 // 访问令牌（脱敏）
  labels?: Record<string, string>; // 标签
  tags?: string[];                // 标记

}
```

### 4.2 API接口
- `GET /admin/kubernetes/clusters` - 获取集群列表
- `GET /admin/kubernetes/clusters/{id}` - 获取集群详情
- `POST /admin/kubernetes/clusters/import` - 导入集群
- `PUT /admin/kubernetes/clusters/{id}` - 更新集群信息
- `DELETE /admin/kubernetes/clusters/{id}` - 删除集群
- `POST /admin/kubernetes/clusters/{id}/test-connection` - 测试连接

### 4.3 安全要求
- **凭证管理**：
  - 敏感信息脱敏显示
  - 证书和密钥加密存储
  - 访问权限控制
- **操作审计**：
  - 记录所有集群操作日志
  - 包含操作者、操作时间、操作内容
  - 支持日志查询和导出

## 5. 性能要求

### 5.1 响应时间
- 集群列表加载：< 2秒
- 单个集群详情：< 1秒
- 集群状态检测：< 5秒
- 导入集群操作：< 10秒

### 5.2 并发支持
- 支持同时管理100+集群
- 支持多用户并发操作
- 状态检测不影响界面交互

## 6. 用户体验要求

### 6.1 易用性
- **操作直观**：关键操作有明确的视觉反馈
- **错误友好**：错误信息具体且提供解决建议
- **状态清晰**：集群状态统一为"测试通过"/"测试失败"，用颜色和图标直观显示
- **状态简化**：将复杂的技术状态简化为用户易理解的测试结果，提升操作体验

### 6.2 响应式设计
- 支持不同屏幕尺寸
- 表格在小屏幕上自适应
- 模态框适配移动端显示
