**测试目标**: 验证四步创建流程正常工作

1. 验证页面标题和步骤指示器
2. 填写任务名称和描述
3. 选择优先级
4. 点击"下一步"

#### 步骤2: 数据配置
1. 选择数据集
2. 调整数据分割比例滑块
3. 验证比例总和为100%
4. 点击"下一步"

#### 步骤3: 模型配置
1. 切换简单模式和专家模式
2. 选择模型和GPU配置
3. 在专家模式下调整超参数
4. 点击"下一步"

#### 步骤4: 回顾启动
1. 验证配置总结信息正确
2. 点击"创建任务"按钮
3. 验证任务创建成功消息
4. 确认跳转到任务详情页

**预期结果**:
- ✅ 四个步骤正确显示和工作
- ✅ 表单验证正常工作
- ✅ 步骤间导航正常
- ✅ 配置信息正确保存和显示
