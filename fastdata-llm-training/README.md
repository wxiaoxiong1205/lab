# fastdata-llm-training

当前仓库中的主应用工程，承担 DeepexiLab 模型训练平台的页面还原、功能补全、页面设计文档融合和后续联调工作。

## 当前定位

这个工程当前更接近“正在持续补全的产品实现工作区”，而不是已经完成的正式标准产品。

目前已知特点：

- 已有较完整的前端页面骨架
- `模型训练 - 大模型训练` 模块相对成熟，默认视为受保护模块
- 其他标准模块仍需持续对照生产环境补齐和修正，包括数据管理、模型评估、模型服务、系统管理等
- 项目中仍存在部分 mock 数据驱动页面
- 后续还需要补齐或联动后端能力，以支持最终部署
- 页面内可编辑需求说明能力已接入统一壳层

## 开发前必须遵守

在本目录进行任何开发前，请先返回仓库根目录阅读：

- `../AGENTS.md`
- `../docs/ai/production-review-template.md`
- `../docs/ai/module-delivery-template.md`
- `../docs/ai/page-design-doc-template.md`

默认规则：

- 先拆解生产环境，再开发
- PRD / RPD 与生产环境冲突时，以生产环境为准
- 如果用户后续明确提出新增或修改需求，需要同步更新实现与 PRD / RPD 理解
- 涉及页面时，可按需调整页面中的运行态需求说明；该说明默认保存在浏览器本地，不自动同步仓库文件
- 未经明确要求，不得修改“模型训练 - 大模型训练”模块
- 不得继续增强非标准功能：业务测试数据集、业务推理结果集、文件管理、业务效果评估、API 服务
- 模型服务、系统管理等标准模块属于正常开发范围，不应被误判为非核心而跳过
