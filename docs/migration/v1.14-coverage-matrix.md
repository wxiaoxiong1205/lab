# V1.14 Coverage Matrix

本矩阵用于指导生产代码替换后的 V1.14 缺口处理。状态说明：

- `production-covered`：生产代码已有，直接采用生产实现。
- `demo-only`：生产代码缺失，需要从 1.0 Demo 按生产规范迁入。
- `partial-conflict`：生产代码已有部分能力，但与 V1.14 验收口径存在差异，需要适配。
- `defer-to-2.0`：属于 2.0 方向，不进入当前生产替换。
