# Modules

本目录用于沉淀模块级长期知识。

## 当前建议优先维护的模块文档

- `project-space.md`
  项目空间、项目概览、系统管理双域结构
- `data-services.md`
  数据服务模块的共享数据结构、任务状态和页面关系
- `system-management.md`
  系统管理模块范围、菜单结构和当前实现边界
- `training-and-models.md`
  模型训练、我的模型、Notebook 与大模型部署的关系

## 使用方式

- 当某个模块连续多轮被迭代时，把稳定下来的结构沉淀到这里
- 不要把一次性临时任务记录塞进这里
- 每个模块文档应优先描述“当前基线”和“待演进方向”
