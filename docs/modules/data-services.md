# Data Services

## 当前定位

数据服务模块已经完成第一阶段主链路补齐，并进入第二阶段持续迭代模式。

## 涉及页面

- 训练数据管理
- 测试数据管理
- 推理结果集
- 数据标注
- 数据清洗

## 当前关键实现

- 共享数据仓储
- 本地 API 层
- 最小本地后端
- 统一任务状态流转 helper

## 当前边界

### 共享仓储

数据服务页面共享同一份本地状态：

- 训练数据
- 验证数据
- 测试数据
- 推理结果
- 标注任务
- 清洗任务

### API 层

页面默认通过 `dataServiceApi` 读写数据，不直接操作底层 store action。

### 本地后端

当前已有一个最小 Node HTTP 服务用于承接数据服务主链路的基础 CRUD。

## 当前技术约定

- 新增数据服务相关操作，优先先加到服务层而不是直接写页面
- 列表查询条件优先收敛到 API 层
- 状态流转约束优先收敛到 `taskLifecycle.ts`

## 当前建议关注点

- 不同页面间的数据联动是否一致
- 数据用途、版本、状态流转是否一致
- 页面内嵌需求文档是否和实际页面同步
