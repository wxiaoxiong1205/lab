# Validation

## 每轮需求后的最小验证清单

### 1. 路由

- 页面是否能正常进入
- 默认跳转是否符合当前壳层结构
- 返回路径是否仍然正确

### 2. 布局

- 顶部导航是否正常
- 左侧菜单是否符合当前导航域
- 页面右侧设计文档侧板是否正常展开 / 收起

### 3. 数据与状态

- 当前项目上下文是否符合预期
- 菜单权限、操作权限、项目权限是否仍然有效
- 关键列表 / 表单是否正常回显

### 4. 构建

- `npm run build` 是否通过

### 5. 文档

- 页面内嵌设计文档是否同步
- 若涉及全局结构变化，`docs/architecture/` 是否需要同步
