# DeepexiLab 2.0 Planning

本目录保存 DeepexiLab 2.0 Agent Native 方向的规划资料。

## Contents

- `CONTEXT.md`：2.0 产品语言和核心概念。
- `PRODUCT.md`：2.0 产品定位、用户、原则和设计边界。
- `deepexilab-2-agent-native-*.md`：PRD、设计方案、需求探索、评审和系统能力规划。
- `prototypes`：2.0 原型和原型说明。
- `research`：调研资料和分析报告。
- `assets`：2.0 规划图和视觉资产。

## Usage

2.0 规划资料是下一阶段产品输入，不直接覆盖生产代码。实施时应以 `production/frontend` 和 `production/backend` 为工程基线，按模块拆解后逐步落地。
